# Summarize Gradings (BMEVIHIAA01)

Collect individual grading reports generated by the `grade-student` skill and produce a concise, structured summary table for all evaluated students.

---

## Workflow

> [!IMPORTANT]
> **Overwrite Guard:** Before writing the summary, check whether `output/grading-summary.md` (or the target summary file) already exists. If it does, **stop and ask the user for confirmation** before overwriting it (unless the user already explicitly asked to overwrite).

### 1. Collect Grading Reports
Locate and read all relevant `grade-student` reports from:
- Individual student report files in `output/*.md` (excluding `output/grading-summary.md`), or another folder/file list specified by the user.
- Prior `grade-student` outputs in the current conversation or referenced subagent outputs.

If a report is missing any required field (e.g., topic or score), note it explicitly as `Missing` rather than guessing.

### 2. Extract Key Fields per Student
For each student report, extract:
1. **Student**: Student name, Neptun code, and/or submission folder name.
2. **Topic**: Homework assignment topic or program title.
3. **Grade (Points)**: Total score out of 10 (e.g., `8.5 / 10`, `4 / 10 (Pass)`, `2 / 10 (Fail)`, or `0 / 10 (Rejected)`).
4. **Most Important Remarks**: A concise, high-signal summary of the critical findings:
   - **AI-authorship suspicion** (highlight prominently, e.g., `**AI suspicion:** ...`).
   - Hard-gate failures or major deductions (compilation errors, memory leaks, `realloc` array instead of dynamic structure, multi-pass file reading, missing/weak documentation).
   - Notable strengths or specific items to verify at the defense (*védés*).

### 3. Generate the Summary Table
Present a Markdown table sorted consistently (e.g., alphabetically by student name or by submission order):

```markdown
| Student | Topic | Grade (Points) | Most Important Remarks |
| :--- | :--- | :---: | :--- |
| <Student Name / ID> | <Homework Topic> | <X / 10> | <Concise key remarks, deductions, AI suspicion if any> |
```

### 4. Add Brief Overview & Save
Below the table, include a short summary block:
- **Total graded**: Count of students, Pass vs. Fail/Rejected breakdown, and average score.
- **Flagged for Defense (*Védés*)**: List any students flagged for suspected AI-written code or borderline/hard-gate issues.

Write the summary table and overview to `output/grading-summary.md` by default (creating `output/` if needed), or to any custom path specified by the user.
